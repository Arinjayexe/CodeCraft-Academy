HTML FUNDAMENTALS

What is HTML?

Introduction to HTML

HTML stands for HyperText Markup Language. It is used to create the structure of webpages. It tells the browser how to display headings, paragraphs, images, links, tables and other content.

HTML is a markup language, not a programming language.

UNDERSTANDING THE CODE

Basic HTML Structure

basic-structure.html

<!DOCTYPE html>

<html>

  <head>

    <title>My Page</title>

  </head>

  <body>

    <h1>Hello World</h1>

    <p>My first page</p>

  </body>

</html>

CONNECT AND DISPLAY

Links and Images

Learn how to connect webpages and display pictures.

Hyperlinks

The anchor tag is used to create clickable links to other pages or websites.

<a href="about.html">About Us</a>
Example: Go to Home →

Images

The image tag displays pictures on a webpage. It uses src and alt attributes.

<img src="photo.jpg" alt="My Photo">

Alt text describes an image if it cannot be displayed.

DATA PRESENTATION

Understanding HTML Tables

Tables organize information into rows and columns.

Important Table Tags

  • <table> – Creates a table.
  • <tr> – Creates a table row.
  • <th> – Creates a heading cell.
  • <td> – Creates a data cell.
  • <caption> – Adds a table caption.
  • <thead> – Groups header rows.
  • <tbody> – Groups table body rows.
  • <tfoot> – Groups footer rows.
USER INTERACTION

HTML Forms

Forms collect information from website visitors.

Common Input Types

  • Text – Enter names and other text.
  • Password – Enter passwords.
  • Email – Enter email addresses.
  • Number – Enter numerical values.
  • Radio – Select one option.
  • Checkbox – Select multiple options.
  • Date – Select a date.
  • Submit – Submit the form.

Basic Form Example

<form>
 <label>Name:</label>
 <input type="text">
 <label>Email:</label>
 <input type="email">
 <button type="submit">Submit</button>
</form>

HTML5 FEATURES

Semantic HTML Elements

Semantic elements describe the purpose of different parts of a webpage.

Element Purpose
<header> Defines the header of a page or section.
<nav> Defines navigation links.
<main> Defines the main page content.

<article> Defines independent content.

MULTIMEDIA IN HTML

Audio and Video Elements

HTML5 allows multimedia content to be added directly to webpages.

Audio Element

Used to add audio files to a webpage.

<audio controls>
 <source src="music.mp3" type="audio/mpeg">
</audio>

Video Element

Used to display videos on a webpage.

<video controls width="300">
 <source src="video.mp4" type="video/mp4">
</video>
HTML CONCEPTS

Block-Level and Inline Elements

Block-Level Elements

These elements generally start on a new line and occupy the available width.

  • <div>
  • <p>
  • <h1> to <h6>
  • <section>
  • <article>

Inline Elements

These elements generally occupy only the space needed by their content.

  • <span>
  • <a>
  • <strong>
  • <em>
  • <img>
