01 - INTRODUCTION

What is JavaScript?

Understand the programming language of the web.

JavaScript is a high-level programming language commonly used to add functionality and interactivity to websites. It works with HTML and CSS to create complete web experiences.

How HTML, CSS and JavaScript Work Together

  • HTML: Creates the structure of a webpage.
  • CSS: Controls the design and appearance.
  • JavaScript: Adds behaviour and interactivity.

Uses of JavaScript

  • Creating interactive buttons and menus.
  • Validating registration and login forms.
  • Building quizzes and calculators.
  • Displaying live updates on webpages.
  • Changing HTML content dynamically.
  • Creating games and web applications.

03 - VARIABLES

Variables in JavaScript

Learn how to store and use information.

A variable is a named storage location used to hold information such as names, numbers and values.

Three Ways to Declare Variables

  • var: Older way of declaring variables.
  • let: Used for values that may change.
  • const: Used for variables that cannot be reassigned.

Example

let name = "Arjun";
let age = 18;

const country = "India";

console.log(name);
console.log(age);
console.log(country);

Here, name stores text, age stores a number and country stores a text value that cannot be reassigned.

05 - OPERATORS

JavaScript Operators

Operators perform calculations and comparisons.

1. Arithmetic Operators

OperatorMeaningExample
+Addition10 + 5 = 15
-Subtraction10 - 5 = 5
*Multiplication10 * 5 = 50
/Division10 / 5 = 2
%Remainder10 % 3 = 1
**Exponentiation2 ** 3 = 8

2. Comparison Operators

  • == checks equality after type conversion.
  • === checks equality without type conversion.
  • != checks inequality after type conversion.
  • !== checks inequality without type conversion.
  • > checks greater than.
  • < checks less than.
  • >= checks greater than or equal to.
  • <= checks less than or equal to.

3. Logical Operators

  • && AND: Both conditions must be true.
  • || OR: At least one condition must be true.
  • ! NOT: Reverses a boolean value.

4. Assignment Operators

let x = 10;

x += 5;  // x = x + 5
x -= 2;  // x = x - 2
x *= 3;  // x = x * 3

06 - DECISION MAKING

Conditional Statements

Make decisions based on different conditions.

1. if Statement

Executes code only when a condition is true.

let age = 18;

if (age >= 18) {
    console.log("Eligible");
}

2. if-else Statement

Chooses between two possible blocks of code.

let marks = 75;

if (marks >= 40) {
    console.log("Pass");
} else {
    console.log("Fail");
}

3. else-if Ladder

Checks multiple conditions one by one.

let marks = 85;

if (marks >= 90) {
    console.log("Grade A");
} else if (marks >= 75) {
    console.log("Grade B");
} else if (marks >= 40) {
    console.log("Grade C");
} else {
    console.log("Fail");
}

4. switch Statement

Useful when comparing one value with several possible cases.

let day = 2;

switch (day) {
    case 1:
        console.log("Monday");
        break;

    case 2:
        console.log("Tuesday");
        break;

    default:
        console.log("Other day");
}

5. Ternary Operator

A shorter way to write a simple if-else condition.

let age = 20;

let result = age >= 18
    ? "Adult"
    : "Minor";

console.log(result);

07 - LOOPS

Loops in JavaScript

Repeat a block of code multiple times.

1. for Loop

Used when we know how many times we want to repeat code.

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

2. while Loop

Repeats as long as the given condition is true.

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

3. do-while Loop

Runs the code at least once before checking the condition.

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

4. for...of Loop

Used to access values from an iterable such as an array.

let fruits = ["Apple", "Mango", "Banana"];

for (let fruit of fruits) {
    console.log(fruit);
}

Loop Control Statements

  • break: Stops the loop.
  • continue: Skips the current iteration.

08 - FUNCTIONS

Functions in JavaScript

Write reusable blocks of code.

A function is a reusable block of code designed to perform a particular task. It runs when it is called.

Function Declaration

function greet() {
    console.log("Welcome!");
}

greet();

Function with Parameters

Parameters allow us to pass information into a function.

function add(a, b) {
    console.log(a + b);
}

add(10, 20);

Return Statement

The return statement sends a result back from a function.

function multiply(a, b) {
    return a * b;
}

let result = multiply(4, 5);
console.log(result);

Arrow Function

A shorter way to write many functions.

const greet = () => {
    console.log("Hello!");
};

greet();

Arrays in JavaScript

Store multiple values inside a single variable.

An array is an ordered collection of values. Each value has an index, and array indexing starts from zero.

Creating an Array

console.log(fruits[0]);
console.log(fruits[1]);

Example

10 - OBJECTS

Objects in JavaScript

Organise related information using properties and values.

An object stores related information in the form of key-value pairs. It can also contain functions called methods.

Example

let student = {
    name: "Aman",

String Methods

Work with text values using built-in methods.

A string is a sequence of characters used to represent text.

Method or PropertyPurpose
lengthReturns the number of characters.
toUpperCase()Converts text to uppercase.
toLowerCase()Converts text to lowercase.

12 - DOM MANIPULATION

Document Object Model (DOM)

Understand how JavaScript interacts with HTML elements.

DOM stands for Document Object Model. It represents the webpage as a tree of objects. JavaScript can use the DOM to read and change webpage content, styles and elements.

Important DOM Methods

  • getElementById(): Selects an element using its ID.
  • getElementsByClassName(): Selects elements by class.
  • getElementsByTagName(): Selects elements by tag name.
  • querySelector(): Selects the first matching CSS selector.
  • querySelectorAll(): Selects all matching elements.

Changing HTML Content

document.getElementById("heading").innerText =
    "Welcome to JavaScript!";

Changing CSS with JavaScript

document.getElementById("heading").style.color = "purple";

Creating an HTML Element

let newPara = document.createElement("p");

newPara.innerText = "This is a new paragraph.";

document.body.appendChild(newPara);

13 - EVENTS

JavaScript Events

Respond to actions performed by website visitors.

Events are actions or occurrences that happen in the browser. JavaScript can detect these events and run code in response.

EventMeaning
clickWhen an element is clicked.
mouseoverWhen the pointer moves over an element.
mouseoutWhen the pointer leaves an element.
keydownWhen a keyboard key is pressed.
submitWhen a form is submitted.
changeWhen an input value changes.
loadWhen a resource or page finishes loading.

Example: Click Event

document.getElementById("myButton")
    .addEventListener("click", function() {
        alert("Button clicked!");
    });

14 - FORM HANDLING

Form Handling and Validation

Collect and check information entered by users.

JavaScript can read form values and check whether the information entered by a user meets certain conditions.

Example

let name = document.getElementById("name").value;

if (name.trim() === "") {
    alert("Please enter your name");
} else {
    alert("Form submitted!");
}

Why is Form Validation Useful?

  • Checks whether required fields are filled.
  • Checks whether an email follows a valid format.
  • Helps prevent incomplete submissions.
  • Displays helpful messages to users.

Client-side validation improves user experience, but important data must also be validated on the server.

15 - BUILT-IN OBJECTS

Math and Date Objects

Use JavaScript's built-in features for calculations and dates.

Math Object

Provides useful mathematical operations.

console.log(Math.round(4.6));
console.log(Math.floor(4.9));
console.log(Math.ceil(4.1));
console.log(Math.max(10, 20, 30));
console.log(Math.min(10, 20, 30));

Date Object

Used to work with dates and time.

let today = new Date();

console.log(today);
console.log(today.getFullYear());
console.log(today.getMonth());
console.log(today.getDate());

Note: getMonth() returns values from 0 to 11, where January is 0 and December is 11.

16 - DATA FORMAT

Introduction to JSON

Understand a common format for exchanging information.

JSON stands for JavaScript Object Notation. It is a lightweight text format used to store and exchange data.

Example JSON Data

{
    "name": "Aman",
    "age": 18,
    "course": "Computer Science"
}

Convert JSON into a JavaScript Object

let data = '{"name":"Aman","age":18}';

let student = JSON.parse(data);

console.log(student.name);

Convert an Object into JSON

let student = {
    name: "Aman",
    age: 18
};

let jsonData = JSON.stringify(student);

console.log(jsonData);

17 - BROWSER STORAGE

Local Storage

Store small amounts of information in the browser.

Local Storage allows a website to store key-value data in the user's browser. The data normally remains available after the browser is closed and reopened.

Storing Data

localStorage.setItem("username", "Aman");

Reading Data

let user = localStorage.getItem("username");

console.log(user);

Removing Data

localStorage.removeItem("username");

Do not store passwords or sensitive personal information in Local Storage.

18 - ERROR HANDLING

JavaScript Error Handling

Handle unexpected errors in a controlled way.

Error handling helps a program respond to problems instead of stopping unexpectedly.

try...catch

try {
    let result = unknownFunction();
    console.log(result);
} catch (error) {
    console.log("Something went wrong.");
}

finally

The finally block runs after try and catch, whether an error occurs or not. 

try {
    console.log("Program started");
} catch (error) {
    console.log("Error occurred");
} finally {
    console.log("Program finished");
}
